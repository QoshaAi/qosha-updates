# Qosha updates

This repository holds only Qosha's signed update files. Qosha on your computer reads them to update itself. There is
no source code and no personal data here.

Every update is signed with Qosha's own key. Qosha checks that signature, and the size and fingerprint of every file,
before it installs anything, so a changed file is refused wherever it comes from.

Questions: contact Qosha AI.
